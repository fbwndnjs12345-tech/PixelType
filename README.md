# PixelType

이미지를 유니코드 문자로 바꾸는 무료 브라우저 도구입니다.

## 기능
- PNG, JPG, WEBP 이미지 선택 및 드래그 앤 드롭 (최대 15MB)
- 문자 너비, 대비, 밝기 반전 조절
- ASCII, 블록 문자, 한글, 기호, 점자 패턴 스타일
- 결과 복사 및 TXT / PNG 저장
- 모바일 화면 대응
- 이미지 파일은 브라우저 안에서 처리하며 서버로 전송하지 않음

## 실행
`index.html` 파일을 브라우저에서 열면 됩니다. 빌드 도구나 패키지 설치가 필요하지 않습니다.

## 한계
이 도구는 이미지의 픽셀 밝기를 문자 밀도로 치환합니다. 이미지의 사물이나 인물을 AI처럼 이해하는 기능은 아니며, 결과는 원본과 문자 세트에 따라 달라집니다.
